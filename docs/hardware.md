# Hardware validation (milestone 5)

The code for the network manager (M5) is complete and covered by unit tests
with scripted fakes, but **it has never run on real hardware**. Everything
below must be executed on the device before M6 starts; record numbers and
observations here.

Boards: **Raspberry Pi 2** (Raspberry Pi OS Lite) and **Cubieboard**
(Allwinner A10, ARMv7, 1 GB, Debian/Armbian). The **BeagleBone Black** is
validated later, in M6.

## 1. WiFi adapter gate

For each board with the dongle plugged in, record:

```sh
lsusb
iw list | grep -A 10 "Supported interface modes"
readlink /sys/class/net/wlan0/device/driver
```

Pass if `AP` is listed in the supported interface modes **and** a 10 minute
manual hostapd test (the config generated by `internal/netmgr/ap.go`) lets a
phone connect. Fail → use an RT5370 or MT7612U dongle and repeat.

## 2. Run in managed mode

```sh
sudo ./wa-transcriber -data /data -network managed -listen :80
```

On the images (`console=serial` in `wat.txt`, see
[../os/README.md](../os/README.md#debug-console)) the same process runs from
inittab and a login shell is available on the UART header: keep
`tcpdump -ni any udp port 5353`, `dmesg` and the web UI Logs page open while
testing, they are the only way to see what the network manager decided.

Check `!status` and `http://wa.local/` after each scenario. Repeat every
scenario 3 times (PLAN.md, M5 exit criteria):

| # | Scenario | Expected | Result |
|---|---|---|---|
| 1 | Cold boot, no saved networks, no cable | `WA-Setup-XXXX` within 60 s; phone joins with the setup key; captive page opens on Android and iOS; `http://wa.local/` and `http://example.com/` both reach the UI | |
| 2 | Add the home WiFi in the UI | joins within 60 s, AP disappears; `http://wa.local/` from a laptop; `!status` shows the new IP | |
| 3 | Wrong passphrase | back to the AP within 2 min, the UI shows the failure | |
| 4 | Router switched off | AP within 2 min (unpaired or no cable); router back → rejoins within 6 min when nobody is on the AP | |
| 5 | Ethernet to the router | `wa.local` reachable within 20 s | |
| 6 | Ethernet straight to a laptop (no DHCP) | link-local address, `wa.local` from the laptop within 40 s | |
| 7 | `!reset` | reboots into AP mode, no saved networks | |
| 8 | 24 h soak in client mode | RSS growth < 10%, goroutine count stable (Status page), no reconnect loops in the logs | |
