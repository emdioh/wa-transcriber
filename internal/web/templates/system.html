{{else}}

Copies this card's boot partition and both system partitions onto {{.Status.Target}} and reads every byte back before saying so. The card is not changed apart from a small marker file ({{.Status.Marker}}) that makes the first start from the internal storage copy the settings, the WhatsApp session and the WiFi networks over, so the phone stays paired. Nothing is downloaded: it works without a network. The progress is in the log, not on this page. If it fails, the card still boots the device and the internal storage is simply not bootable yet: run it again. When it is done, power the device off, remove the SD card and power it on again — the board boots from the card when one is inserted.
