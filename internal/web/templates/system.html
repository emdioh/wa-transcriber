Backup

Everything that makes this device itself: the settings and the password, the transcription API key, the WhatsApp link and the saved WiFi networks. Keep the file somewhere safe and upload it after a reflash, on a new card or on a replaced device: it comes back paired, with the same key and the same networks.

⚠ The file contains the transcription API key, the WhatsApp session and the saved WiFi passwords. Anyone who has it can use your API key, act as your WhatsApp device and join your networks. Store it like a password, and delete old copies.

Download the backup

Uploading replaces the settings, the WhatsApp link and the WiFi networks on this device with the ones in the file, then restarts it: reload this page in about {{.ReloadSecs}} seconds. Take a fresh download first if you are not sure. A file that is damaged or not a backup is refused and nothing changes.
